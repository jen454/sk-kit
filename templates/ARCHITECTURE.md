## 전체 구조
```
[화면: 운영자 / 사용자]
      │ HTTP JSON
[router: 입력 검증] → [service: 비즈니스 규칙] → [repository: DB 접근] → [SQLite]
      ↑ 에러: service가 AppError → 전역 핸들러가 400/404/409/500 JSON으로 변환
[loader: 제공 데이터 → 검증 → DB, 시작 시 1회]
```
